# ENS — Esquema Nacional de Seguridad

Document management repository for **ENS (Spain's National Security Framework)** compliance at **optimTech / Optimpeople**.

## What's Here

Structured ISMS (SGSI) compliance and governance documents, version-controlled with git. No source code — just policies, procedures, records, and evidence organized by ENS best practices.

See [CLAUDE.md](CLAUDE.md) for the full directory structure and document naming conventions.

## Directory Overview

| Folder | Contents |
|--------|----------|
| `01_POLITICAS/` | Security policies |
| `02_NORMAS/` | Standards, instructions, forms |
| `03_PROCEDIMIENTOS/` | Operational procedures |
| `04_REGISTROS/` | Registers and compliance records |
| `05_ROLES/` | Job role descriptions |
| `06_EVIDENCIAS/` | Implementation evidence (signed docs, vendor certs, screenshots) |
| `07_AUDITORIA/` | Audit documents and accreditations |
| `08_GOBERNANZA/` | Committee acts, org charts, awareness |
| `09_NORMATIVA_EXTERNA/` | External regulations, CCN-STIC references |
| `10_PROCEDIMIENTOS_APLICADOS/` | Applied procedures / SOPs |
| `PLANTILLAS/` | Document templates |
| `snapshots/` | Frozen yearly archives |

## Claude Code Skills

This repo includes Claude Code skills for working with Office documents: **docx**, **xlsx**, and **pptx** (read, edit, create).

## Integration

- **Confluence** (ENSCORP space) — living knowledge base for ENS documentation
- **Jira** — project management and task tracking
- **Git** — canonical store for formal binary documents (.docx, .xlsx, .pdf, .pptx)
